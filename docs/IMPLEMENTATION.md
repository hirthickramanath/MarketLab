## Verification scope

`npm test` covers accounting, fees, weighted averages, overspending, reservations, duplicate order IDs, integer overflow, session expiry/cutoffs, realized P&L, rational FX conversion, drawdown, ratios, scoring, indicators, persistent password auth, transaction rollback, funding idempotency, classroom isolation and PostgreSQL RLS/immutable ledger behavior.

Playwright desktop/mobile workflows exercise demo login, an actual order, a 15-minute session, refresh restoration, manual completion/report, quiz progress, journal persistence, original educational-reference links, dark mode, and absence of horizontal page overflow. API tests exercise unauthorized funding, user isolation, duplicate submissions, cross-origin rejection, and administrator credits. Additional browser tests exercise email/password registration, logout and repeat login. Expiry is exercised with explicit domain timestamps and persisted expired records; browser tests do not wait 15 minutes and should not be described as having done so.

The PostgreSQL migration is validated using PGlite with a minimal test Auth schema, **not against a hosted Supabase project**. Browser screenshots cover selected desktop/mobile screens; every production page has not had visual acceptance review. CI configuration is provided but no GitHub Actions run has been observed.
